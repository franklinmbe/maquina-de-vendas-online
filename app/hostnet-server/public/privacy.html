Política de Privacidade — Máquina de Vendas Online

Última atualização: 27 de agosto de 2026

A Máquina de Vendas Online (app.franklinmorais.com) é um serviço que ajuda pequenos negócios a criar e publicar conteúdo (fotos, vídeos e legendas) nas próprias redes sociais. Esta página explica quais dados coletamos, para que usamos, e como o cliente pode revogar o acesso a qualquer momento.

1. Quais dados coletamos

  • Cadastro: nome, e-mail ou telefone, e uma senha (guardada apenas como hash irreversível — nunca em texto puro).
  • Conteúdo enviado pelo cliente: fotos, vídeos e instruções de texto/áudio que o cliente envia para serem publicados.
  • Tokens de acesso de redes sociais: quando o cliente conecta uma rede social (Facebook, Instagram, TikTok, YouTube, Telegram, WordPress), recebemos e guardamos um token de acesso (nunca a senha da rede social) cifrado em nosso servidor, usado exclusivamente para publicar o conteúdo que o próprio cliente pediu.
  • Estatísticas de uso: quantidade de pedidos, fotos e vídeos enviados, e datas de login — usadas apenas para o relatório administrativo do próprio negócio.

2. Para que usamos esses dados

Usamos os dados exclusivamente para prestar o serviço contratado: publicar o conteúdo que o cliente envia nas redes sociais que ele mesmo conectou. Não vendemos, alugamos ou compartilhamos esses dados com terceiros para fins de publicidade.

3. Como os tokens de redes sociais são protegidos

Os tokens de acesso são cifrados antes de serem salvos e só são usados para as chamadas de API necessárias à publicação do conteúdo autorizado pelo próprio cliente. O cliente pode revogar esse acesso a qualquer momento diretamente nas configurações da respectiva rede social (Facebook, Instagram, TikTok, YouTube, etc.), o que invalida o token imediatamente.

4. Exclusão de dados

O cliente pode solicitar a exclusão completa da sua conta e de todos os dados associados (cadastro, tokens, histórico de pedidos) a qualquer momento, entrando em contato pelo e-mail abaixo. O pedido é atendido em até 7 dias.
